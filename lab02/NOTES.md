Рабочая папка -- папка, где происходят создание, изменения файлов проекта

Индекс -- буферная зона для изменений

Коммит -- сохранение изменений



Git -- это инструмент для отслеживания создания проекта

GitHub -- облачный сервис с репозиториями, где можно отслеживать это самое создание



git diff смотрит разницу между рабочей папкой и индексом

git diff --staged смотрит разницу между индексом и последним коммитом



раздел «Использованные команды»

git status -- показывает текущее состояние репозитория, измененные файлы и в индексе

git diff -- сравнивает рабочую папку с индексом

git diff --staged -- сравнивает индекс с последним коммитом



раздел «Ветки»

Ветка -- отдельная линия разработки внутри проекта

Каждый новый коммит в текущей ветке сдвигает указатель на себя

При слиянии происходит объединение изменений в разных ветках
