Рабочая папка -- папка, где происходят создание, изменения файлов проекта

Индекс -- буферная зона для изменений

Коммит -- сохранение изменений



Git -- это инструмент для отслеживания создания проекта

GitHub -- облачный сервис с репозиториями, где можно отслеживать это самое создание



git diff смотрит разницу между рабочей папкой и индексом

git diff --staged смотрит разницу между индексом и последним коммитом
