git diff показывает разницу между последним коммитом и текущим состоянием репозитория

git show отображает подробную информацию об объекте Git

git log выводит список коммитов, зафиксированных в репозитории, начиная с самых новых



git log -S показал коммиты, в которых была изменена конкретная строчка

git blame проаннотировал каждую строчку файла информацией о последнем коммите, который ее изменил



git restore восстанавливает файл из индекса, используется для отмены незакоммиченных изменений в файле (все незакоммиченные изменения в файле безвозвратно удаляются)

git restore --source= восстанавливает файл из указанного коммита (текущие незакоммиченные изменения в файле перезаписываются и теряются, файл становится таким, каким был в выбранном коммите)
